📖 பயன்படுத்தும் முறை – Instructions

  1. இனி வரும் காலங்களிலும் அகவிலைப்படி சதவீதங்கள் மற்றும் நிலுவை கோரப்படும் மாதங்களை மாற்றி கணக்கீடு செய்யலாம்.
  2. அலுவலகம் மற்றும் பணியாளர்களின் விபரங்களை Manual ஆக உள்ளீடு செய்ய Number of employees in the Bill இல் எண்ணிக்கையை உள்ளீடு செய்து Create Employee Rows ஐ click செய்யவும்.
  3. IFHRMS report ஐ Import செய்தும் தானாக விபரங்களை பதிவு மேற்கொள்ளச் செய்யலாம்.
    IFHRMS இல் Download செய்யும் வழிமுறை: Human Resource → Report Viewer → Employee Basic Details Report ஐ Excel format இல் download செய்து, Import Employees from IFHRMS file ஐ click செய்து விபரங்களை Import செய்யலாம்.
  4. Import செய்த பின்னர் ஏதேனும் பணியாளர்கள் அந்த BILL GROUP இல் இல்லை எனில் அவர்களை மட்டும் DELETE button ஐ click செய்து நீக்கலாம்.
  5. பணியாளரின் Surrender, Increment, Selection grade, Special grade, Promotion ஆகிய விபரங்களை சரியான தேதியுடன் பூர்த்தி செய்யவும்.
  6. அனைத்து விபரங்களும் பூர்த்தி செய்த பின் Calculate DA Arrears என்பதை Click செய்து Report generate செய்து Calculation Sheet ஐ Print செய்து கொள்ளலாம்.
    Calculate DA Arrears கொடுத்த பின் கணக்கீட்டில் மாற்றங்கள் IFHRMS calculation ஐ ஒப்பிடும்பொழுது ஏதேனும் இருப்பின் Manual ஆக சரி செய்த பின் print கொடுக்கலாம்.
  7. இதில் மேற்கொள்ளப்படும் செயல்பாடுகள் தற்காலிகமாக மட்டுமே சேமிக்கப்படும். எனவே இதே விபரங்களை பின்னர் பயன்படுத்தவும், வேறு கணினிகளில் பயன்படுத்தவும் JSON file ஆக (Download JSON) செய்துகொண்டு, பின்னர் Import JSON மூலம் மீண்டும் பயன்படுத்தலாம்.
